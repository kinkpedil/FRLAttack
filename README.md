# FRLAttack

Database lap time komunitas untuk game **FR Legends**. Pemain mengirim screenshot best lap, sistem memverifikasi waktunya dari screenshot, lalu waktu yang lolos masuk ke leaderboard tiap sirkuit.

Status: Fase 0 (riset dan persiapan).
